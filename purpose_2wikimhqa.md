# Wiki Research Direction

## Core Positioning
Structured knowledge base compiled from Wikipedia paragraphs in the 2wikimhqa dataset, used as the retrieval backend for multi-hop question answering.

## Ingestion Focus
- Priority: key facts, entity relationships, temporal information, causal connections.
- Moderate: background context, categorical information.
- Skip: redundant information already captured in other pages.

## Target Use Case
Multi-hop question answering — questions that require combining information from multiple paragraphs or entities.
